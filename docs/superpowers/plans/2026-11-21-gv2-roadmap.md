# Gedcom.Vector 2.0.0 Plan Roadmap

Spec: `docs/superpowers/specs/2026-11-21-gedcom-vector-2-0-design.md` (approved 2026-11-21).

The design spans several subsystems, so it is delivered as a sequence of plans, one per phase. Each plan produces working, tested software on branch `feature/v2.0` and is written in detail only once its predecessor has landed, because later plans name types and signatures that earlier plans create. Each plan ends with all tests green, zero warnings, the AOT job green, and a whole-plan code review.

**Benchmarks throughout (user requirement):** a start-point run on unchanged 1.3.2 (.NET 8), the .NET 10 baseline in Plan 1, and a checkpoint row in `docs/benchmarks/history.md` after every task that touches parsing, the model, writing or the context, via `tools/Run-Benchmarks.ps1`. A row over +10% against the baseline is raised in that task's review, not left for Plan 8. Rows record allocated bytes as well as the mean. The export benchmarks are gated against the lower of the .NET 8 start point and the .NET 10 baseline, because the .NET 10 figure carries a background-GC cost caused by the 1.3.2 writer's allocations (`docs/benchmarks/2026-11-22-export-gc-investigation.md`).
