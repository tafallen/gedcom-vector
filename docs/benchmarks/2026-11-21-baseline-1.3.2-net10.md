The two export rows (`MeasureExporting`, `MeasureExportingContext`) carry a background-GC cost from the 1.3.2 writer, so they are gated against the lower of this baseline and the .NET 8 start point (1.54 ms and 1.47 ms, see [2026-11-21-start-1.3.2-net8.md](2026-11-21-start-1.3.2-net8.md)) rather than against this baseline alone. Against those references this baseline run is +34.8% and +49.8%; Plan 5's writer allocation budget targets this gap.
